ValuationProof — 기준일 CB 조건 × 평가 Excel 대조 (합성 데모)

전환사채 공시·정정공시 사슬에서 평가 기준일에 유효한 조건을 고르고, 평가 Excel 입력 셀과 대조해 근거 보고서를 만드는 결정론 도구 · 코드 github.com/ThakiCloud/thaki-valuationproof · Apache-2.0

모든 데이터는 합성(SYNTHETIC)입니다. 가상 발행사 SYNTH001의 가상 공시 사슬(원공시 1 + 정정 3)과 합성 평가 Excel 4종입니다. 실제 회사·실제 공시·실제 회계사 평가모형이 아닙니다. 결과는 사람이 검토할 후보(PENDING)이며, 자동 수정이나 공정가치 계산은 하지 않습니다. All data is synthetic; findings are review candidates, not verdicts.
한계 (V4.1 고정판)
  • 전환가액조정 공시는 자동 수집하지 않습니다. chain["adjustments"]로 넣을 때만 반영됩니다.
  • 실제 DART 공시의 모든 조건을 완전히 감사한다고 주장하지 않습니다.
  • 공개 표본에서 '표시 없이 틀린 값 0건'은 그 표본(60개사)과 두 해석(IA/IB) 범위 안의 결과입니다. 정확도 100%가 아니라, 불확실한 조건을 확인 필요로 돌린 결과입니다.
  • 그 대가로 분기말 24.3%(138/567)는 사람이 확인해야 합니다.
  • 실제 회계사 Excel로는 평가하지 않았습니다.
  • V4.2(조정공시 자동 수집·bitemporal)는 개발 중인 로드맵입니다.
